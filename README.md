# 💰 FinAassist

**FinAassist** is an AI-driven financial advisor built to bridge the financial literacy gap across Africa.  
It combines **voice-first interaction**, **localized financial insights**, and **real-time spend tracking** to empower users—regardless of literacy level—to make smarter financial decisions.

---

## 🌍 Vision

Millions of people across Africa remain underserved by traditional financial tools due to:
- Language barriers  
- Low financial literacy  
- Limited internet access  

**FinAassist** addresses this by delivering:
- Simple, actionable insights  
- Voice-based interaction  
- Offline-first accessibility  

---

## 🚀 Core Features

### 🗣️ Multilingual Voice Interface
- Speech-to-text and text-to-speech support  
- Languages:
  - English  
  - French  
  - Kinyarwanda  
  - Swahili  
- Designed for non-literate and visually impaired users  

---

### 🤖 AI Financial Advisor
- Python-powered intelligent assistant  
- Analyzes income and spending patterns  
- Provides real-time, actionable insights  

Example:
> “Your food spending is up 15% this week”

---

### 📊 Visual-First Dashboard
- Icon-driven UI for intuitive navigation  
- Designed for low-literacy environments  
- Quick understanding of financial status  

---

### 🚗 Real-World Loan Assessment
- Evaluates affordability for:
  - Cars  
  - Motorbikes  
- Based on real financial behavior, not assumptions  

---

### 📈 Financial Health Profiling
- Manual input for:
  - Income  
  - Expenses  
- Generates a **Financial Health Score (0–100)**  

---

### 📶 Offline-First Experience
- Local storage using SQLite  
- Users can:
  - Log transactions  
  - View balances  
- Works without internet connectivity  

---

### 🎯 Smart Expense Categorization
Tracks local spending categories:
- Transport (Moto / Bus)  
- Food  
- Rent  
- Airtime / Data  

---

### 🧠 Behavioral Coaching
- Detects “spending leaks”  
- Provides actionable advice  

Example:
> “Airtime is 15% of your income — consider cheaper bundles”

---
